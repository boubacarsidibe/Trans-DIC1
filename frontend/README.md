# Frontend Trans-DIC1

Interface React 19 construite avec Vite, React Router, Axios et Tailwind CSS.

## Commandes

```powershell
npm ci
npm run dev
npm run lint
npm test
npm run build
npm run preview
```

La variable `VITE_API_BASE_URL` permet de remplacer l'URL par défaut `http://localhost:8080/api/v1`. Définissez `VITE_AUTH_REQUIRED=true` pour activer la protection des routes dès que l'API d'authentification sera disponible.
